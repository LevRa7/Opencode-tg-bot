# v0.17.0 Semantic Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade this customized branch from `0.14.1` to a working `0.17.0`-level release without breaking local multi-user orchestration, user approvals, threaded/forum routing, or Docker/runtime customizations.

**Architecture:** Execute the upgrade as a semantic port on top of the current branch, not a direct upstream merge. Protect local invariants with regression tests first, then port upstream `v0.14.1..v0.17.0` changes in dependency-safe phases: baseline protection, version/deps/config, rendering/streaming, thinking-vs-final-response separation, new commands, selective runtime alignment, and final verification/documentation. Preserve the current grammY bootstrap invariants throughout the port: existing `bot.use(...)` order, the single `bot.on("callback_query:data")` dispatcher, the central `bot.api.config.use(...withTelegramRateLimitRetry...)` transformer, `bot.catch(...)`, and the long-polling startup/shutdown lifecycle in `startBotApp`.

**Tech Stack:** TypeScript, Node.js 20+, npm, Vitest, grammY, OpenCode SDK, Telegram Bot API
