Terminal Agent Architecture

OpenCode Telegram Bot worktree: /home/me/opencode-tg/.worktrees/terminal-agent

Telegram user → grammY bot → state managers + OpenCode SDK → SSE summary pipeline → Telegram delivery

Entry & Control

  • src/index.ts boots runtime mode and logging.
  • src/app/start-bot-app.ts coordinates startup.
  • src/config.ts centralizes typed environment config.

Core Data Flow

  • Telegram updates enter the bot layer.
  • OpenCode events stream back through the summary pipeline.
  • Replies are routed to the same chat or forum topic.

State & Safety

  • Session, model, question, permission, and thread state live in managers.
  • Scheduled tasks and process control run alongside the foreground flow.
  • Optional STT / TTS / translation services extend the runtime.
